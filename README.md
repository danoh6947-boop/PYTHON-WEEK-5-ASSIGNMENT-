# Week 5 Assignment - Modules

## Files

- `password_generator.py` - Uses the random and string modules to generate random passwords of different lengths.
- `helpers.py` - Contains functions for calculating the number of tables needed and creating welcome messages.
- `main.py` - Imports the helpers module and uses its functions.

The hardest function to write was `tables_needed()` because I had to understand how `math.ceil()` rounds a number up. I learned that 10 people with 4 seats per table need 3 tables.
